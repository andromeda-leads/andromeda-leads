Требования к фото: портрет по грудь, лицо по центру кадра, горизонтальное и вертикальное
одинаково подходит (на сайте фото обрезается в круг 140×140), разрешение от 600×600, вес до 400 КБ.

Пока файла нет - на сайте автоматически показывается монограмма с инициалами,
вёрстка не ломается. Как только фото появятся, они подхватятся сами.
